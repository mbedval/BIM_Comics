# CLI Command Reference Sheet

This document contains a compilation of shell commands to test and showcase all the capabilities of the **BIS Comic Renderer** framework. You can copy and execute these commands directly in your terminal to see the various artistic rendering styles.

---

## 1. Directory Setup & Pre-requisites

Ensure you have sample images inside the input folder:
```bash
# Verify the presence of input files
ls -l images/input/story1/
```

---

## 2. Dynamic Info Commands

Discover available rendering presets dynamically configured in the framework:
```bash
# List all available presets
python3 bis_comic_main.py --list-presets
```

---

## 3. Presets Showcase Commands

Below are the commands to execute each of the 10 presets. These commands will read images from `images/input/story1`, render them, and output the resulting PNG files inside `images/output/story1/`.

### 2. Film Noir Style
Deep-shadow, high-contrast B&W style inspired by 1940s film noir. Emphasizes dark shadows, morphology dilation, and multiply-blending.
```bash
python3 bis_comic_main.py --storypath images/input/story1 --preset noir --overwrite
```


### 5. Pencil Sketch Style
Soft pencil look using a Sobel operator for outline rendering combined with coarse drawing paper textures.
```bash
python3 bis_comic_main.py --storypath images/input/story1 --preset pencil_comic --overwrite
```

### 6. Sin City Noir Style
Crushed midtones using custom ToneCurve lookup mappings and thick dilated Canny edge lines.
```bash
python3 bis_comic_main.py --storypath images/input/story1 --preset sin_city --overwrite
```

### 7. Newspaper Halftone Style
Newsprint screen look generated by rotated coordinate grids (45 degrees screen angle) with custom blend overlay.
```bash
python3 bis_comic_main.py --storypath images/input/story1 --preset newspaper --overwrite
```

### 8. Vintage Warm Print Style
Aged warm print using warm-toned sepia vignettes (`[45, 30, 15]`) and heavy paper fiber textures.
```bash
python3 bis_comic_main.py --storypath images/input/story1 --preset vintage_print --overwrite
```

### 10. Woodblock Woodcut Style
Coarse woodblock relief texture look.
```bash
python3 bis_comic_main.py --storypath images/input/story1 --preset woodcut --overwrite
```

### 11. Anime Style
Hand-drawn animation style using AnimeGANv2 style transfer.
```bash
python3 bis_comic_main.py --storypath images/input/story1 --preset anime --overwrite
```

### 12. Cartoon Style
Stylized, painterly cartoon/comic illustrations using Satoshi Kon's Paprika style transfer.
```bash
python3 bis_comic_main.py --storypath images/input/story1 --preset cartoon --overwrite
```

## 4. Execution Modifiers (Performance & Logging)

Test parallel processing and verbose execution parameters:

### Run with Specific Thread/Process Workers Count
```bash
# Run in parallel using exactly 2 worker processes
python3 bis_comic_main.py --storypath images/input/story1 --preset noir --overwrite --jobs 2

# Run in parallel automatically using all available CPU cores
python3 bis_comic_main.py --storypath images/input/story1 --preset noir --overwrite --jobs 0
```

### Run with Verbose/Debug Details
Disables the tqdm progress bar to output step-by-step filter execution latency logs:
```bash
python3 bis_comic_main.py --storypath images/input/story1 --preset noir --overwrite --verbose
```

### Background Removal Integration
Leverages the `withoutbg` library to automatically remove the background from images prior to running the style filters:
```bash
# Remove background and composite onto a white background (default)
python3 bis_comic_main.py --storypath images/input/story1 --preset woodcut --overwrite --remove-bg

# Remove background and composite onto a black background
python3 bis_comic_main.py --storypath images/input/story1 --preset noir --overwrite --remove-bg --bg-color black
```
